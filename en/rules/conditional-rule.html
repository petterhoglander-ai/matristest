Rule type in matrix reasoning tests

Conditional rule

How the rule works

One attribute governs another: if the shape is a triangle it is always striped, if the first symbol is a ring the second is always a diamond. The link is the same throughout the matrix, but which value sits where may follow another rule.

It is a rule about pairs, not about direction. It is invisible if you read the row as a series, and only shows when you compare cells that have the same shape or the same first symbol. Two cells with the same condition must look the same in what is conditioned.

Rules in the example

  • The fill determines the direction: filled means 90°, unfilled means 270° and dotted means 0°.
  • Everything else is the same in every cell.

How to recognise it

  1. Find two cells with the same shape or the same first symbol. Do they also have the same fill or second symbol?
  2. Write down the pairs: triangle means striped, square means solid. Check that no pair breaks.
  3. Decide the empty cell's condition from the row or column, then look up the pair.
