Rule type in matrix reasoning tests

Slot by slot combination

How the rule works

Every cell has three slots in a row with one symbol each, or empty. The third cell is worked out slot by slot from the first two: one symbol is neutral and changes nothing, two equal symbols become the neutral one, and two different symbols among the other three become the third. The answer says which symbol is neutral and which the other three are. The rule holds in rows and columns at the same time.

This is the rule that makes the harder tests hard: the table cannot be guessed, it has to be read from the complete rows. Look for a row where two equal symbols stand in the same slot in the first two cells, and see what stands there in the third. That is the neutral symbol. The rest follows.

Rules in the example

  • The third cell is worked out slot by slot from the first two: two equal symbols become a flag pointing left, a flag pointing left changes nothing, and two different ones among a star, a square and a circle become the third. This holds in rows and columns.
  • Everything else is the same in every cell.

How to recognise it

  1. Find a complete row where the same symbol stands in the same slot in cells one and two. The symbol in that slot in cell three is the neutral one.
  2. Find a slot where the neutral symbol stands in one cell: the symbol in the other should remain in cell three. Two different symbols give the third.
  3. Work out the empty cell slot by slot from the last row, and check against the last column. Both must give the same cell.
