Rule type in matrix reasoning tests

Number of sides

How the rule works

The number of corners on the figure increases or decreases by one for every cell: triangle, square, pentagon, hexagon. The rule can run to the right, downwards or both. The circle is not included; it has no corners to count.

It is a step by step change in the shape instead of the number. It is missed because the shapes look different rather than like a series, and because the difference between six and seven corners is small on screen. Count, do not guess.

Solved example

The bottom right cell is the answer, marked. The explanation below the matrix is the same text the app gives.

Rules in the example

  • The number of corners decreases by 1 to the right and 1 downwards.
  • Everything else is the same in every cell.

Level 2 in the app. The same example is shown in the app after a wrong answer on this rule. Rules in the example: Number of sides.

How to recognise it

  1. Count the corners on the figure in every cell of the first row. Do they grow by one per step?
  2. Do the same downwards in the first column.
  3. Work out the number of corners in the empty cell, then count the corners in every option.
